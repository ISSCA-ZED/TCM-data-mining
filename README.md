# TCM Data Analysis Project

A comprehensive data analysis project for Traditional Chinese Medicine (TCM) research, focusing on disease-symptom-herb relationships across different dynasties.

## Project Structure

```
TCM/
├── Code/                    # Python analysis scripts
│   ├── 1.LLM.py           # LLM extraction evaluation
│   ├── 2.Disease_name_evolution.py
│   ├── 3.Symptom_evolution.py
│   ├── 4.Herb_Gini+Pattern.py
│   ├── 5.Formula_combination.py
│   ├── 6.Formula_herb_Z_score.py
│   ├── 7.Entity_network_TF-IDF.py
│   ├── 8.Network_Pharmacology-Pathway_evolution.py
│   ├── 9.New_symptom-formula_herb.py
│   └── 10.Isolated_path.py
├── Data/                    # Input data files
│   ├── Disease name/
│   ├── Entity network/
│   ├── Formula herb/
│   ├── Herb/
│   ├── LLM/
│   ├── Network Pharmacology/
│   ├── Symptom/
│   └── Entity-Normalized.xlsx
└── Results/                 # Output files (generated by scripts)
```
